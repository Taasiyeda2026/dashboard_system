# נתוני פתיחה - הכשרות קורסים וערכות

הנתונים הוזנו ישירות ל-Supabase באישור המשתמש:

- 110 מצבי הכשרה, מתוכם 53 מסומנים כהכשרה שהושלמה.
- 39 ערכות שמוחזקות אצל מדריכים.
- ערכת "ביומימיקרי חדר בריחה" נשמרה כפריט ערכה לא פעיל עם מלאי: מחסן 0, הילה 1, עידן 1, גיל 2.

המסמך הוא תיעוד בלבד ואינו מבצע שינוי נתונים.
