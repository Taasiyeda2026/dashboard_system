# חיבור הדשבורד לנושמות השראה

הכניסה למשחק מופיעה בקיצורי הדרך בלוח הבקרה של המדריכות. המשחק פועל ב־`https://portzot-derech.org/inspiration/teacher.html` ומתחבר בנפרד לפרויקט הדשבורד `szinlhjuwyiyszdpsdop`; אין שינוי בהתחברות או בהרשאות של מודולים קיימים.

## חיבור בין המקורות

מכיוון שהקורס והדשבורד פועלים במקורות שונים, המשחק פותח חלון `inspiration-bridge.html?origin=…&state=…` בדשבורד. הדשבורד מאמת את ה־session באמצעות `auth.getUser(access_token)` ומחזיר אותו ב־`postMessage` רק למקור המפורש `https://portzot-derech.org` או `https://taasiyeda2026.github.io`. חיבור localhost מותר רק כאשר גם הדשבורד נמצא ב־localhost. `state` הוא nonce אקראי של 32–128 תווי base64url, שנבדק גם בחלון המשחק. חלון המשחק חייב לבדוק מקור, מקור החלון (`event.source`) ו־state לפני קליטת ההודעה.

אסימונים אינם נכתבים לכתובת, ל־query string או ללוג. אם אין session תקף, החלון עובר למסך ההתחברות הקיים; בקשת החזרה נשמרת רק ב־sessionStorage של חלון זה ותוקפה עשר דקות. לאחר התחברות רגילה מוחזר החלון לגשר קבוע באותו מקור. אין יעד חזרה חופשי. דף הגשר מוחרג מהמטמון של ה־Service Worker.

תצוגת קיצור הדרך אינה הרשאה. שרת המשחק חייב לאמת את המשתמש דרך Supabase Auth ולבדוק `public.users.auth_user_id`, `is_active` והתפקיד `instructor`/`admin` או הרשאה מפורשת `permissions.inspiration_manage: true`. אין להשתמש בטוקן היישום המותאם של הדשבורד כהוכחת הרשאה.

## אימות ופריסה מתואמת

בדיקות הגשר: `node tests/inspiration-session-bridge.test.mjs`.

יש לבדוק בסביבת בדיקה את שני המקורות: פתיחת המשחק מדשבורד מחובר, session שפג וחזרה מההתחברות, חלון קופץ חסום, וסירוב משתמש ללא הרשאת משחק. בניית Vite חייבת לכלול את `inspiration-bridge.html` כ־entry נפרד. אין להעביר אסימונים בכתובת לצורך פתרון תקלה בחלונות קופצים.

הפעלת המשחק תלויה גם ב־PR של `portzot-derech`, בהחלת Migration המשחק ובהתקנת שירות המשחק בפרויקט Supabase של הדשבורד. לא בוצעו כאן שינויים במסד הייצור, בהגדרות Auth, פריסה או מיזוג. יש לתאם את הפריסות לאחר אישור מפורש של הבעלים.
